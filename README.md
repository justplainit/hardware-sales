# hardware-sales

Minimal Next.js + TypeScript starter to use with Cursor AI.

How to run locally
1. Install: `npm install`
2. Dev: `npm run dev` (opens at http://localhost:3000)
3. Build: `npm run build` && `npm start`

Notes for Cursor
- Open this repository in Cursor.dev to continue development with AI assistance.
- Environment variables are listed in `.env.example`.

What’s included
- Next.js + TypeScript minimal app
- Dockerfile for containerized runs
- GitHub Actions workflow for CI
